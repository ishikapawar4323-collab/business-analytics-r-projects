# Business Analytics using R

This repository contains academic R-based analytics projects and statistical analysis exercises completed as part of business analytics coursework at the University of Delhi.

## Topics Covered

* Exploratory Data Analysis (EDA)
* Descriptive Statistics
* Missing Value Handling
* Skewness & Kurtosis Analysis
* Vector and Matrix Operations
* Simple & Multiple Linear Regression

## Tools & Libraries

* R
* RStudio
* moments package

## Datasets Used

* airquality
* mtcars

## Key Learning Outcomes

* Statistical data interpretation
* Analytical problem-solving
* Structured reporting workflows
* Regression analysis fundamentals
* Data handling and visualization in R

## Repository Files

* airquality-statistical-analysis.R
* regression-analysis-mtcars.R
* r-programming-fundamentals.R
